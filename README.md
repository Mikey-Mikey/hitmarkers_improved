# Customizable Hitmarkers
Fully customizable hitmarkers for NPCs and Players!

## Features
* Visual hitmarkers drawn around your crosshair
* Customizable sounds for normal, headshot, and kill hits
* Damage numbers displayed next to the crosshair
* Armor hit indicator (blue marker + armor icon)
* Fully customizable via the in-game menu
* Preset support for quick configuration

## How to use
Open the spawnmenu and go to Utilities -> Hitmarkers -> Settings. All options are adjustable there, including a sound browser and color mixer.

## Customization options

| Option | Description |
| ------ | ----------- |
| Count |	Number of hitmarkers around the crosshair (1-360) |
| Offset | Angle Starting angle of the markers |
| Lifetime | How long markers stay on screen |
| Length / Width | Size of each marker |
| Spacing | Distance from crosshair |
| Rotation Speed | Animated rotation of markers |
| Spread Speed | Markers spread outward over time |
| Color | Marker color (RGB) |
| One Only | Show only one hitmarker at a time |
| Armor Icon | Toggle armor indicator with X/Y offsets |
| Sounds | Custom sound paths for basic, headshot, and kill hits |
| Volume | Sound volume (0-2) |
